6 · RULES
01A match with no events published shows no chevron. An empty panel is never correct.
02Events are feed order — chronological. Do not group by team or by type.
03In-progress matches show events up to the last sync, under the same age note as the score.
04Leagues without published crests use the abbreviation in the side column, as everywhere else.
No events endpoint exists yet — the prototype carries hand-written fixtures for the six played matches. This panel is the first surface in the app that needs per-minute match data, so it gates on that feed, not on UI work.
