Anatomy
CARD
Radius 22, padding 13 / 14, 12px gap to the attachment. System material; the mock uses rgba(30,37,44,.72) + blur 28 and a 0.5px rgba(255,255,255,.09) hairline.
HEADER
App icon 16×16 radius 4.5 · app name 12/500 uppercase 62% white · relative time 12/500 52% white, trailing. 5px below.
TITLE
15/600, −.012em, #fff. Event word uppercase, then the running score: GOAL · Athletic Club 2–1 Getafe. Score always in the title so the alert is useful unread.
BODY
15/400, −.012em, 78% white, 2px below the title. Scorer and minute, then assist if known, then one clause of consequence. Two lines maximum.
META ROW
9px below the body. Time left, then total yellows, then total reds, then a red-card consequence in #ff8f7c. All 11/600 tabular at 62% white; card glyphs 7×10; 1px 10-tall dividers at 14% white; 10px gaps. Segments drop out when zero — the row itself disappears if only the clock is left.
ATTACHMENT
38×38, radius 9. Goal: accent plate rgba(200,242,90,.13) on a rgba(200,242,90,.3) hairline, struck-ball glyph 21×18 centred. Cards: same plate in the card colour with the card glyph. One attachment only — see the MD.
